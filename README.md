User Management System (Java)


Шаблоны проектирования приложений
Модуль 02 – Принципы проектирования

Описание
Простая система управления пользователями для небольшой компании.
Реализованы операции добавления, удаления и обновления пользователей.

Каждый пользователь содержит:
- имя
- email
- роль (Admin / User)

Принципы проектирования
- YAGNI – реализован только необходимый функционал
- KISS – простой и понятный код без лишних абстракций
- DRY – повторяющаяся логика вынесена в отдельный метод
